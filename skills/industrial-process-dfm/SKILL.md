# 工艺设计与可制造性审查

先记录每个零件的工艺、材料、批量阶段、主要功能面和可见面。工艺尚未决定时，比较可行路线及其对造型、分件和装配的影响。方向、材料、机床、模具和批量变化时，重新检查适用的限制。

| 工艺 | 核对内容 |
| --- | --- |
| 注塑 | 定拔模方向和分型线，查负拔模、倒扣、局部壁厚和厚薄过渡、筋与柱连接、工具薄钢、浇口和顶出区。加纹理后复查有纹理面的拔模。 |
| CNC | 以装夹和刀轴方向核对内角可达半径、深窄槽的刀具伸出、薄壁夹持、二次装夹基准和共轴孔的加工路径。 |
| 钣金 | 先定义料厚和工厂折弯规则，检查内半径、孔与折弯区的距离、折弯避让、展开和折弯顺序。 |
| 增材 | 结合工艺和摆放方向核对最小特征、支撑、孔道清理、层方向、接触面与后加工余量。打印样机的规则按其工艺使用。 |
| 包胶或双料 | 核对基材相容性、机械锁固、收边封胶、表面高度渐消、包胶厚度、定位和脱模。将视觉边界与止口或模具封胶面对应。 |

## 在 CAD 中取证

1. 先标定脱模或加工方向，再沿该方向做分析。厚度检查覆盖凹面背后、开孔与螺钉柱旁、台阶转角及包胶渐消区。记录测量方向、位置和参考公差。
2. 逐个接口写清单边、直径及轴向间隙的含义。把涂层、纹理、收缩、密封件压缩等工艺变量纳入适用的公差链。对需实测的生产配合，分别记录名义模型、最差条件和样件数据。
3. 出现问题时先定位控制特征。能通过改变内壁或座肩解决时，优先保护外形。需要拆件、移动分型或改加工方向时，在相同视图复查外观和装配影响。
4. 记录零件与位置、实测值、依据来源、影响、候选修正和复测状态。阈值来自本项目确认的供应商、设备、材料规格或适用标准。缺少依据时标待确认，保留实测值。
