# Rhino 圆角与倒角

在建面前写清该边的目的、目标半径或倒角尺寸、需要的连续性，以及允许消耗的接触平面和壁厚。区分决定外轮廓的造型过渡、接触或导入边、末端去锐微圆角。

## 按意图选构造

| 意图 | 构造 | 要验证的量 |
|---|---|---|
| 实体边的圆弧过渡 | FilletEdge，按边设半径和局部半径控制点 | 截面半径、G1 切向、剩余壁厚 |
| 部件导入、明确切面或机械去锐 | ChamferEdge 或独立倒角面 | 两侧退距与安装平面保留量。弯曲边上的直纹倒角面可能整体不共面 |
| 两张独立母面之间的圆角 | FilletSrf 或 VariableFilletSrf | 取面侧、轨线、相切及修剪结果 |
| 外观高光要求曲率连续 | 留出过渡带，使用 BlendSrf 或受约束 NURBS | 边界位置、切向、曲率和面内反射 |
| 一段圆角宽度或高差退回母面 | 先定义渐消方向和结束截面，再选变半径或独立退让面 | 末端截面、母面上的连续性和有效拓扑 |

圆弧半径连续变化一般仍属于相切过渡。要求 G2 时单独验证曲率。RollingBall 用于按滚轮半径理解的过渡，基于退距或轨线距离的选项用于控制带宽。跨边段用实际邻接关系与位置识别边，布尔后重新识别边，避免沿用旧边号。

## 操作和排错

1. 在最窄截面、锐角端、孔边及三面交会处预看圆角占用空间，检查是否侵入内腔、座肩、分缝或相邻件。
2. 对同一组相邻过渡通常先大后小。确定轮廓的大过渡尽量先在干净母面或实体做完。孔口收边在孔形成后做。仅在无功能意义的共面边妨碍求解时考虑合并。
3. 先以开放过渡预览轨线和留边。有可见孤岛、翻面、尖点或宽度突变时，分段定位第一处失效。大半径不足时，优先判断能否缩短边链、移开切口、改变半径分配，或用独立过渡面重建局部。
4. 对三条边相遇的角区，单独规划过渡终止线和角补面。把自然面边留给 MatchSrf，需要匹配到现有裁剪边时保留其原有母面，并在补面一侧调整。
5. 在对应截面复测尺寸，检查显著转角的曲率图或 Zebra。实体还应检查 IsValid、闭合、裸边和非流形边。替换不了原半径时记录实际尺寸和失败边段。

同一组边发生局部失败时，保留操作前的输入，先在最窄段或三边角做小范围试算。每次只改一个变量，优先检查选边、切削后的退距和三边角是否需要单独补面。圆弧半径在近似法截面上测量。自由曲率过渡记录带宽和曲率连续性。
