# 工业产品装配公差链

## 定义功能结果

- 在装配姿态下指定共同基准、测量方向和位置。分别定义侧隙、轴向间隙、径向间隙、段差、搭接量或压缩量。屏幕和异形嵌件按左右、四角、高点与最窄截面分别取值。
- 从最终结果追溯经过的零件和定位特征。逐项记录符号、名义值、上下限、来源与适用状态。区分成品尺寸、毛坯尺寸、涂层后尺寸及组装后的变形。用同一基准的尺寸求差时先检查相关项会不会抵消。
- 壳体与装饰件间隙同时受尺寸和中心偏移影响。计算总间隙后，把横向定位误差分配到每一侧。凹槽圆角、斜壁、方向偏差及插入路径用实际剖面或极限姿态复核。

## 选择分析方法

1. 对线性尺寸链，先建立 `F = Σ aᵢ xᵢ`。每项用 `min(aᵢLᵢ, aᵢUᵢ)` 求其下界，用对应最大值求上界，再相加。保留不对称和单向公差。各项可能同时达到极限时，以最差范围对照功能限值。
2. 记录单项幅度和灵敏度，找出使结果跨过要求的主导项。可比较调整定位、移动名义设计或修改零件公差的效果。工艺提供分布与相关性时，再分别给出 RSS 或统计模拟的假设与结果。名义 CAD 量测、最差范围、统计估计和样件实测分别报告。
3. 涉及位置度公差区、基准移动、材料条件修饰符、形位相关性或角度误差时，根据图纸给出的标准与基准体系建立实际约束。用剖面、极限几何或测量方案验证功能边界。只有缺失的约束得到确认后，才给出相应项目的结论。

## 算例与输出

以一个假设的开口为例。开口成品宽 `30.00 ± 0.15 mm`，嵌件宽 `29.60 +0.05/−0.10 mm`。总间隙名义值 `0.40 mm`，极限为 `0.20–0.65 mm`。若独立中心偏移最多 `0.08 mm`，最差单边间隙为 `0.20/2 − 0.08 = 0.02 mm`。真实设计还要核对最窄截面和装入姿态。

交付时记录结果量、方程、方向和配合截面。给出名义值、最差上下限、功能限值、主导贡献项与资料缺口。生产公差需要供应商或适用规范的依据，样机结论注明试制工艺和测量条件。
