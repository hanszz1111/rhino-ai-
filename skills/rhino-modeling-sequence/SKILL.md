# Rhino 工业产品建模顺序

先区分控制外观的母面、控制装配的基准与配合，以及附着在前两者上的细节。优先做会被多处引用、变化后会影响外轮廓或分件的几何。

## 建模顺序

1. **锁定基准与功能边界。** 确定单位、轴向、对称面、关键截面、最大包络、安装平面和插入方向。由图片取比例时，保留一个独立的尺寸基准，并在截面上记录参考差异。
2. **检查外形母面。** 先建正背主面、侧壁、顶底端面等决定轮廓的几何，再做肩部、腰部和边界过渡。用代表性的正交视图和截面检查比例，保护后续需要用作切槽或匹配面的母面。
3. **解决一级过渡与分件。** 影响轮廓和主要高光的大圆角、平面肩部或渐消带属于造型，通常与母面一起做。用主面划分分模线和材料边界，确认端面定位后再构建内壳与开口。
4. **准备壳厚与装配。** 用内外壳或可靠偏移确定壁厚。有双曲率紧弯、变壁厚或偏移将自交的区域，单独构建内面、检查截面厚度，再封口。饰板、玻璃和握胶应从同一母面与基准派生槽口、座肩及插入间隙。
5. **落位功能特征与末端细节。** 扣位、螺钉柱、埋入台阶和切口应引用确定的基准。仅属于孔、槽和装配导入口的边缘处理，在这些特征已经存在后做。纹理、微圆角和字标放到形态及装配都稳定之后。
6. **在依赖边界检验。** 主面阶段看切线和高光，壳体阶段看闭合与厚度，装配阶段看静态交集和所需的插入路径，收尾阶段检查局部半径、局部裸边与视图。记录失败从哪一阶段引入，修正最早的相关特征。

## 保留可回退的工序

- 开始时把外形尺寸来源、目标配合间隙、连续性指标和文档公差记入同一张基准表。由参考图推得的量保持可识别。
- 建完决定轮廓的母面就保留一份。切壳、切槽工具和细节放在派生件上。迟到的造型更改先判断依赖，再决定回改母面还是只修改开口或嵌件。
- 关键布尔先核对预演结果和切除区域。工具支持 dry_run 时读取预测对象数和有效性。确认保存后的交付文件，再清理临时几何。

## 根据特征改变先后

- 大外圆角会改变外包络，且薄壳或孔槽会妨碍半径时，在干净实体或母面上预先建立它。
- 孔口微圆角依赖孔本身。先有孔口，再按该口的参考边做圆角或导入角。
- 如果分件沿连续造型穿过，先做共用母面再切壳。玻璃密封面、PCB 固定面等装配基准会决定外形时，可以先定义平面和保留空间，再约束后续外形。
- 复合装配的局部更改只重建受影响的母面和下游零件。需要修改原生文档时，保留改前基线并按阶段核对几何。

## 手持仪器例

六视图轮廓与主截面 → 前后母面、顶底平面和肩部 G2 过渡 → 前后壳及分缝 → 饰框座、屏幕座、侧握胶槽、同轴探头座 → 按键、导孔、边缘处理与纹理。先定顶屏窗口的保留区域，具体切孔放在顶面和肩部定形之后。
