# Rhino 参考装配与真实接口

1. **测源模型。** 核对文档单位与版本。展开或遍历嵌套块时应用父子变换，检查缩放、镜像和轴向。记录源零件名、对象标识、测得的定位面与坐标。需要保持原件形状时只应用刚体变换。
2. **锁住功能基准。** 用主安装平面、次方向和定位特征建立可复查的坐标系。镜组开孔从有效光路和装配口型提取。显示屏分别记录厂家模组包络、可视区、盖板、排线和走线空间。优先以真实轮廓或原剖面派生异形孔。
3. **从接口派生外壳。** 先建立壳体的开合面、壳内包络、安装方向和维修空间，再做位置受限的屏幕平面、端盖止口、开口和座肩。用平面方程核对接合面的倾角和法向间距。标明单边间隙、厚度、压缩量与名义值的来源。
4. **验证静态和路径。** 对有效闭合件做体积交集，区分允许接触、零体积、失败和实体重叠。沿实际方向查看插入中的截面，在最窄点、姿态变化处及进入止口前后取样。对于原始开面，记录点或剖面检查的覆盖范围和未完成的体积检查。
5. **交付可复查的文件。** 把原组装件、派生外壳、材料分件和核对剖面设置成可独立查看的图层。存盘复开核对关键源零件的数量、尺寸、布置及对象标识。

### 常见接口

- **垂直屏幕。** 核对盖板、丝印净开口、模组和板件。量安装面的法向、盖板厚度、可视区遮挡、装入深度与四周留边。
- **前盖与光孔。** 圆形使用实际光轴和直径，异形沿真实口型截面。跨截面核对通光轮廓，同时检查前盖止口、孔间筋及邻近卡扣。
- **目镜或旋钮。** 从原件提取轴线、安装肩和旋转包络，检查路径及调节状态下的周向空隙。
