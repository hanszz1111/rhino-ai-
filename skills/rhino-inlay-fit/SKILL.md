# Rhino 嵌件与装配配合

把嵌件接口定义为一组有方向的配合。记录容纳件、嵌件、进入方向、定位基准、侧向间隙、轴向间隙、承载座肩及有意的接触或压缩。保留外观母面、最终嵌件和切槽工具之间的对应关系。

## 构造

1. **确定入位空间。** 平面玻璃优先沿安装平面法向进入，侧握胶按实际装配方向，同轴件以轴线和止口定位。硬质件需满足真实开口尺寸。要检查运动时，以起始位姿到目标位姿扫掠或分段取样。
2. **先建嵌件与可见面。** 从同一母面或边界派生嵌件外轮廓。可见分缝单独由产品外观控制，侧隙和背面深度由装配决定。复合曲面深槽的宽差应在不同截面复查。
3. **再建切槽体和座肩。** 按侧向和轴向间隙分别调整轮廓及深度。让切槽工具穿过应去除的区域，并检查工具不穿透需要保留的壳壁。倾向把工具作为独立实体保留一轮。双曲率胶件可用真实槽壁回切背面，并沿入槽方向留设计间隙。
4. **把接口分成可独立测量的部位。** 玻璃与密封框包含周边带和座肩。同轴部件按轴截面分别标注直径、单边径向和轴向余量。螺钉座区分头部沉座、杆部和导孔。
5. **保留功能面并制作剖面。** 剖切最长、最窄和变化最大的区域。分别标出可见包覆、承载面、留边和壳厚。布尔或切割后检查原母面边界及实体闭合。

## 验收

- 按接口列出需要验证的零件对。先做边界盒排除明确分离的对，再对潜在重叠进行布尔交集或以剖面交叉确认。空结果、求解失败和零体积接触要分开记录。
- 沿实际安装方向测量从嵌件背面到槽底的距离。复杂曲面应在两端、转折和中段取样。法向距离、轴向行程和最小壁厚分别表述。
- 保存后重新读取关键配合。对需要真实装配的设计，记录制造公差、形变和插入路线是否被验证。
