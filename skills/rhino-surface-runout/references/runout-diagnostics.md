# 渐消端部诊断与方案比较

## 沿用同一组设计基准

- 冻结外围轮廓、定位平面、分缝和机芯包络。保存母面、统一方向的纵向参考轨和代表剖面。比较方案时，固定反射环境、相机、剖面站和最大允许外包络。
- 以实测峰值凹深、从何处开始回落、回落长度和横向过渡宽度描述每个候选。按沿轨弧长设置起段、峰值、窄段、终点前后站点。端部外侧也留一站，检查高光进入原母面后的走势。
- 遇到终点挤压时，依次判断是凹深回落过快、横截面退化，还是碰到分型或嵌件限制。保持峰值比较更长的退让距离，或保持退让距离对比不同凹深。必须收成尖端时，在截面尚有有效宽度处结束主带，再设计独立端片。

## 先定位偏差，再改善曲面

| 现象 | 复核位置与下一步 |
| --- | --- |
| 双侧接缝均平顺，中间仍有亮斑 | 沿纵向和横向看面内曲率梳。找出多余的曲率峰或反向变化，减少控制截面或调整站距。 |
| 过渡结束处斑马纹突然折向 | 先量该处接缝位置和法向差，再看横越接缝的法曲率。若有尖端或极短边，回到母面重划端片。 |
| 正视顺畅，斜视有高光拧转 | 检查轨向、截面对应、闭曲线缝点和端区的控制点分布。沿实际纵向再加一条相邻剖面验证。 |
| 高光达到预期，但切槽后有薄壁 | 对比切槽前的母面和切槽后的剩余壁，沿装配方向检查座肩。比较调整内壁、移动峰值或提前结束渐消的影响。 |

## 记录可复测的证据

1. 对真实接缝用 `EdgeContinuity` 量位置、相切与曲率偏差，另用 `Zebra` 或反射图看跨缝和面内高光。记录误差位置、取样方向和实际采用的阈值。接近端部、短边和局部峰值时提高采样密度。
2. 在 RhinoCommon 中复测时，以同一几何位置在两面求参数。先统一法向方向并量夹角。取接缝切线与共同法向确定的切平面内横向，在两面各自的切平面上投影并归一化。用方向 `d`、主方向 `e₁, e₂` 和主曲率 `k₁, k₂` 计算 `kₙ = k₁(d·e₁)² + k₂(d·e₂)²`。法向翻转时同步换曲率符号。端点方向不稳定时加查邻近截面，标出未能量测的位置。
3. 对每个候选保留反射图、对应剖面、最大位置偏差、最大法向夹角、采样得到的横向曲率差和最小壁厚的位置。分别记录面际连续性和面内光顺。完成修剪、拼接和开槽后，在同一批功能位置复测。
